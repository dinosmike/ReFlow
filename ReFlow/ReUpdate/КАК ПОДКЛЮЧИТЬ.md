# ReUpdate — автообновление и «Что нового»

Папка переносится в любую WPF-программу (.NET 6 и новее), которая выкладывает релизы на GitHub.

## Что внутри

| Файл | Зачем |
|---|---|
| `ReUpdateConfig.cs` | Настройки модуля под конкретную программу: репозиторий, имя exe, язык, цвета |
| `Updater.cs` | Тихое автообновление: проверка релизов, скачивание, подмена exe, перезапуск |
| `Changelog.cs` | Загрузка `changelog.json` и учёт «что уже видели» |
| `WhatsNewWindow.cs` | Окно «Что нового» (собрано кодом, без XAML) |
| `DownloadStats.cs` | Скрытая статистика: сколько раз скачали и сколько обновились (счётчики GitHub) |

## Как подключить к другой программе

1. Скопировать папку `ReUpdate` в проект рядом с `.csproj`.

2. В корень репозитория положить `changelog.json`:
   ```json
   {
     "versions": [
       { "version": "1.0", "date": "2026-11-20", "ru": ["Первая версия"], "en": ["First version"] }
     ]
   }
   ```
   И вшить его в exe — в `.csproj`:
   ```xml
   <ItemGroup>
     <EmbeddedResource Include="..\changelog.json" LogicalName="changelog.json" />
   </ItemGroup>
   ```

3. В `App.xaml.cs` в начале `OnStartup` (после проверки «один экземпляр»):
   ```csharp
   ReUpdate.ReUpdateConfig.Owner = "dinosmike";
   ReUpdate.ReUpdateConfig.Repo = "ИмяРепозитория";
   ReUpdate.ReUpdateConfig.AssetName = "Имя.exe";
   ReUpdate.ReUpdateConfig.AppDataFolderName = "ИмяПрограммы";
   ReUpdate.ReUpdateConfig.Language = () => "ru";            // или язык из настроек программы
   ReUpdate.ReUpdateConfig.AutoUpdateEnabled = () => true;    // или галочка из настроек
   ReUpdate.ReUpdateConfig.IsBusy = () => false;              // «занята» — обновление подождёт
   // По желанию цвета под тему программы:
   // ReUpdate.ReUpdateConfig.Colors = new ReUpdate.ReUpdateColors { Accent = ... };
   ReUpdate.Updater.CleanupAfterUpdate();
   ReUpdate.WhatsNewState.Initialize();
   ```
   В конце `OnStartup`, когда главное окно уже создано:
   ```csharp
   ReUpdate.Updater.Start(Dispatcher);
   ```
   Если программа запущена с аргументом `ReUpdate.Updater.UpdatedArg` (`--updated`), её только что обновили. Её лучше стартовать тихо, в трее.

4. Показ «Что нового»:
   - открыть окно: `ReUpdate.WhatsNewWindow.ShowFor(владелец)`;
   - есть ли непрочитанное (для точки-значка): `ReUpdate.WhatsNewState.HasUnseen`, а при изменении приходит событие `ReUpdate.WhatsNewState.Changed`.

5. Скрытая статистика (по желанию): `await ReUpdate.DownloadStats.LoadTextAsync()` — готовый текст со счётчиками; например, показать его в окне «О программе» по правому клику на «ОК».

## Как выпускать новую версию

1. Поднять версию в `.csproj` (`Version`, `AssemblyVersion`, `FileVersion`).
2. Добавить версию в начало `changelog.json` (дата — в формате `ГГГГ-ММ-ДД`).
3. Сделать релиз на GitHub с тегом, в котором есть номер (`Имя_1_3`, `v1.3`, `1.3`), и приложить exe с тем же именем, что `AssetName`.
4. Приложить к релизу ещё раз тот же exe под именем `Имя-update.exe` (например, `ReFlow-update.exe`). Его качает только автообновление, поэтому счётчик скачиваний этого файла на GitHub = сколько программ обновилось (примерно сколько живых пользователей). Посмотреть счётчики:
   ```
   gh api repos/dinosmike/ИмяРепозитория/releases --jq ".[] | .tag_name, (.assets[] | \"  \(.name): \(.download_count)\")"
   ```
   Если этого файла нет, автообновление качает обычный exe.

Программы со старой версией сами найдут релиз в течение суток (или при следующем запуске, через 30 секунд), скачают его, подменят exe и перезапустятся. После этого у значка «Что нового» появится точка.

## Ограничения

- Работает только у опубликованной сборки одним файлом (single-file exe); при запуске из Visual Studio обновление отключено.
- Если exe лежит в папке без прав на запись (например, Program Files), обновление молча не произойдёт.
